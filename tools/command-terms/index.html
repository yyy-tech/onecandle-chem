IB DP CHEMISTRY · COMMAND TERMS

DP化学 指示用語の日英対訳と答え方

IBの試験問題は、文頭の指示用語（command term）で「何をどこまで書けば得点になるか」が決まります。このページでは、DP化学でよく使われる指示用語について、英語と日本語の対応、求められている答え方、化学の例題、よくある失点を、答え方の型ごとにまとめました。

使い方の3つのポイント

1. まず指示用語に印をつける

問題を読んだら、最初に指示用語を丸で囲みます。内容を知っていても、求められていない形で答えると点になりません。

2. 配点から書く量を決める

配点が［2］なら、採点項目が2つあると考えて、別々の要素を2つ書くのが目安です。同じ内容を言い換えても点は増えません。

3. 日本語と英語の両方で覚える

日本語で受験する場合、試験では日本語の指示語で出題されます。英語の教科書や過去問も使うので、両方を対応させて覚えておくと迷いません。

「詳しく述べる」と「説明する」の違い

最も点を落としやすい組み合わせです。同じ現象で比べます。

Describe ＝ 詳しく述べなさい

何が起きるかを書きます。

マグネシウムリボンを希塩酸に入れると、表面から気体の泡が激しく発生し、リボンはしだいに小さくなって溶けてなくなる。溶液の温度が上がる。

Explain ＝ 説明しなさい

なぜそうなるかを書きます。

マグネシウムは水素よりイオン化傾向が大きいため、Mg が電子を失って Mg2+ に酸化され、その電子を H+ が受け取って H2 に還元される。この反応は発熱反応なので温度が上がる。
